# Deck QA

Четыре прохода, все обязательны. Проверять **рендер**, а не код и не «на глаз в редакторе».

## Проход 1 — содержание

- [ ] Один слайд — одна мысль, читается за три секунды.
- [ ] Заголовки — утверждения, не темы.
- [ ] Нет текста, который докладчик произносит вслух.
- [ ] Каждая цифра имеет источник и единицу измерения.
- [ ] Нет заголовков с точкой в конце, нет висячих предлогов в конце строк.
- [ ] Заметки докладчика заполнены, но не дублируют слайд.
- [ ] История имеет вход, развитие и вывод; нет слайда «спасибо за внимание».

## Проход 2 — визуал (по рендерам)

- [ ] Текст не выходит за границы фигур и слайда, ничего не обрезано.
- [ ] Ничего не наложилось: подписи на линии, цифры на текст, футер на контент.
- [ ] Поля не меньше 0,5 дюйма; элементы не липнут к краю.
- [ ] Всё выровнено по общей линии; левые края текста совпадают.
- [ ] Повторяющиеся элементы (номер, рубрика, кредит) стоят на одном месте.
- [ ] Акцент использован не больше двух-трёх раз на слайд.
- [ ] Есть фокусный элемент; при прищуре видно, с чего читать.
- [ ] Соседние слайды различаются архетипом.
- [ ] Контраст текста и фона достаточный для проектора.
- [ ] Текст стоит в спокойной части фото, а не на яркой Земле/Солнце.
- [ ] Подписи тел не лежат на дисках планет; `m₁`/`m₂` над или под.
- [ ] Шапка и кредит видны поверх полноэкранного изображения.
- [ ] Кроп не отрезает главный объект; full-bleed не растянут.
- [ ] Кредиты фото читаемы и не спорят с контентом.

## Проход 3 — движение (по видео)

- [ ] Нет чёрного провала между слайдами.
- [ ] Нет белой вспышки.
- [ ] Нет двух заголовков в середине перехода.
- [ ] Объект не летит через текст, подпись или лицо.
- [ ] Fade 0,1 с, Morph 0,5 с; длиннее — только по явной просьбе.
- [ ] Луна/планета/формула действительно доезжает до конечной точки.
- [ ] Финальный кадр совпадает со статикой слайда.
- [ ] Morph стоит только на стыках с общими объектами; остальное — fade.
- [ ] Видео экспортировано из PowerPoint, а не собрано из статики.

## Проход 4 — техника

- [ ] Файл открывается и проходит `validate.py`.
- [ ] Шрифты доступны на машине показа (или встроены).
- [ ] Кириллица не подменяется другим шрифтом.
- [ ] Нет placeholder-текста, «Lorem», «Слайд 1», пустых фигур.
- [ ] Изображения с правом использования, источники записаны.
- [ ] В ZIP нет служебных папок (`*/`), иначе облако может не открыть файл.
- [ ] Заметки докладчика выгружаются.
- [ ] PDF и видео собраны из финального файла, а не из промежуточного.
- [ ] Размер файла разумный.

## Известные дефекты и их причины

| Симптом | Причина | Лечение |
|---|---|---|
| Чёрный кадр в переходе | Нет общих объектов у Morph | Fade на этот стык |
| Белая вспышка | Нет заливки фона слайда | `slide.background = { color: "000000" }` |
| Шапка исчезла на фото | Фото добавлено после текста | Сначала фото, потом шапка |
| Два заголовка в морфе | Совпали текстовые блоки | Уникальные имена или fade |
| Земля обрезана | Неверный кроп/размер картинки | Пересчитать 16:9 и положение |
| Подпись на диске Луны | `m₂` попала в область картинки | Вынести над/под диск |
| Гигантская цифра обрезана | Кегль больше высоты блока | Увеличить блок или уменьшить кегль |
| Подпись перечёркнута линией | Линейка и текст на одной координате | Развести на 0,1–0,2 дюйма |
| Таблица выглядит «решёткой» | Полные границы ячеек | Только горизонтальные линейки |
| Широкий текст уезжает за край | Поворот: блок задан узким | Задать размеры до поворота |
| Кириллица «другим шрифтом» | В шрифте нет кириллицы | Проверить cmap и рендер в PowerPoint |
| Ряд карточек «как у нейросети» | Контейнер вместо композиции | Убрать заливку и скругление |
| PDF «без переходов» | Это PDF | Показывать PPTX; PDF только резерв |

## Финальная приёмка

1. Открыть контакт-лист и видео у пользователя — не только отдать путь.
2. Показать 3–4 ключевых слайда рендером.
3. Перечислить, что осталось плейсхолдером (ФИО, группа, дата).
4. Сказать, что не проверено: проектор, шрифты на чужой машине, печать.
5. Указать, что PDF не сохраняет переходы, а PPTX требует PowerPoint 2019/365.
