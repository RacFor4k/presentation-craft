# PPTX toolcraft

Практика генерации .pptx кодом. Проверено на pptxgenjs + PowerPoint COM (Windows) и
на LibreOffice (Linux/macOS).

## Пайплайн

```
генератор (js/py) → .pptx → рендер в PNG → просмотр всех слайдов → правки → повторить
```

Без рендера не считать слайд готовым: код не показывает наложений и обрезки.

## pptxgenjs: что ломается

- `pres.layout` ставить **до** добавления слайдов. По умолчанию 10×5,625 дюйма, а не 13,3.
- Цвета — строка без `#`, ровно 6 знаков. `#FF0000` или альфа в hex портят файл.
- Опции объектов мутируются: нельзя переиспользовать один объект `shadow`/`options`.
- `margin: 0` на каждом текстовом блоке, иначе текст съезжает относительно линий.
- `valign` по умолчанию центрирует: если нужен верх — `valign: "top"` явно.
- Списки: `bullet: true` на каждом пункте и `breakLine: true`, не символ «•» в тексте.
- `rectRadius` работает только у `ROUNDED_RECTANGLE`.
- Тени: `offset` не бывает отрицательным.
- Один `new pptxgen()` на файл.
- Гигантский кегль: блок должен быть выше глифа примерно на 10 %, иначе буква обрезается.
- Поворот: размеры блока задаются **до** поворота; узкий блок сложит текст по буквам.
- Таблицы: `addTable` рисует полную сетку. Для «печатного» вида собрать таблицу
  вручную — текстовые блоки плюс горизонтальные `line`.

## Шрифты

- Безопасный набор с кириллицей: Arial, Arial Black, Calibri, Segoe UI, Georgia,
  Times New Roman, Consolas.
- Пара «Arial Black + Arial» даёт сильный контраст весов и не требует установки.
- Экзотические шрифты — только если пользователь их пришлёт; иначе подстановка на защите.

## Рендер на Windows

```powershell
powershell -ExecutionPolicy Bypass -File scripts/render_windows.ps1 -Pptx deck.pptx -OutDir slides
```

Скрипт открывает файл в PowerPoint (невидимо), экспортирует PNG в 1600×900 и
переименовывает в `s-01.png`… Если файл открыт в PowerPoint у пользователя — сначала
закрыть, иначе экспорт и перезапись упадут.

## Рендер на Linux/macOS

```bash
bash scripts/render_linux.sh deck.pptx slides
```

Внутри `soffice --headless --convert-to pdf` и `pdftoppm`. LibreOffice хуже
воспроизводит шрифты: проверять текст на обрезку с запасом.

## Валидация

`python <pptx-skill>/scripts/office/validate.py deck.pptx` — схема, связи, чарты.
Для колод из шаблона добавлять `--original template.pptx`.

## Проверка текстом

`python <pptx-skill>/scripts/slide_text.py deck.pptx` — вытащить всё содержимое и
посмотреть, нет ли забытого placeholder, дублей и опечаток.

## Заметки докладчика

`slide.addNotes("...")` — одно-два предложения. Это единственное место, где уместен
развёрнутый текст: на слайде он мешает.
