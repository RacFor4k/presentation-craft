# Anti-AI checklist

Почему колода читается как «сделано нейросетью»: модель воспроизводит усреднённый
удачный слайд — и он повторяется у всех. Лечится не косметикой, а отказом от дефолтов
и проверкой на общность.

## Маркеры и контрмеры

| Маркер | Почему выдаёт | Контрмера |
|---|---|---|
| Плакат: гигантское слово, пустое поле, декоративная орбита | Красивая форма без содержания; так выглядит почти любой AI-пробник | Реальный объект, читаемая колонка, схема/данные |
| Золото на чёрном, светящиеся орбиты «космос» | Дешёвый космический шаблон | Настоящее фото NASA/ESA + кредит, один сигнальный акцент |
| AI-рендер планеты/станции как «фото» | Нет реального материала | Настоящий кадр или подпись «иллюстрация» |
| Кремовый/бежевый фон, ржавый акцент | Домашняя палитра одного инструмента | Палитра из материала и условий показа |
| Крупный серифный шрифт с курсивом | Подпись генератора | Один шрифтовой закон на колоду |
| Цветная плашка над заголовком, капсовый eyebrow | Декорация без смысла | Убрать; номер раздела мелким в углу |
| Скруглённые карточки с иконкой | Контейнер вместо композиции | Линейки, отбивки, воздух |
| Ряд одинаковых плиток с цифрами | Дашборд вместо аргумента | Одна схема/таблица; цифры тише |
| Всё одного веса | Нет фокусной точки | Контраст масштаба 5–10 раз |
| Один макет на все слайды | Взаимозаменяемость | 5+ архетипов страниц |
| Иконки вместо изображений | Украшение вместо доказательства | Реальная схема, чертёж, фото, данные |
| Тени, градиенты, 3D-буквы | Оформление ради оформления | Плоско, волосяные линии |
| Текст на яркой части фото | Не проверили кадр | Перекроить кроп; спокойная зона |
| Тяжёлый скрим на пол-слайда | Лечение плохой композиции | Найти кадр с чёрным небом/тенью |
| Morph на каждом стыке | «Красиво листается» | Morph только для общих объектов; остальное fade |
| Два заголовка в переходе | Совпали текстовые блоки | Уникальные имена или fade |
| Белая вспышка / чёрный провал | Нет заливки фона / нет общих объектов | `slide.background` + fade |
| Arial Black + Georgia по умолчанию | Самый частый шаблон генератора | Шрифт из материала и машины показа |
| Текст-заполнитель «в современном мире» | Языковой маркер генерации | Конкретика: факт, дата, цифра |

## Проверки

**Материал.** Убери фото/схему/данные. Слайд всё ещё объясняет? Значит материал был
декором, а не доказательством.

**Заморозка.** Слайд понятен без перехода? Если нет — движение несёт информацию,
которой нет на странице; перенеси её на слайд.

**Подмена темы.** Подставь другую тему. Дизайн всё ещё работает? Значит он нейтральный
и не выведен из содержания.

**Прищур.** Отойди на три метра или уменьши слайд: видно, с чего начать читать?
Если всё слилось в ровное поле — нет иерархии.

**Ритм.** Разложи миниатюры. Соседние должны отличаться архетипом: кадр, артефакт,
схема, формула, таблица, фото, вывод. Три одинаковых подряд — переделать.

**Речь.** Слайд дублирует то, что говорит докладчик? Убрать текст, оставить образ
или цифру.

## Язык на слайдах

- Заголовок — утверждение: «Дальше — слабее», а не «Зависимость силы».
- Никаких «данный», «в современном мире», «играет важную роль», «не только… но и».
- Тире и кавычки — по нормам языка, не как декор.
- Числа с единицами и источником в подписи; округление одинаковое по колоде.

## Когда «просто» — правильно

Минимализм не равен пустоте. Допустимо: большой белый лист и одна фраза; одна схема
на весь слайд; две колонки через линейку. Недопустимо: пустой слайд без фокуса,
мелкий текст «чтобы влезло», декоративная сетка без роли, гигантское слово вместо
аргумента.

## Самая частая ошибка

Сначала нарисовать плакат, потом искать материал. Правильный порядок обратный:
материал → мысль → система → пробники на реальном материале → согласование → сборка.
