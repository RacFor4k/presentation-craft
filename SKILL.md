# Presentation craft

Слайды делаются не «по шаблону», а от темы: сначала исследование визуальных референсов,
потом 2–3 черновика-пробника на выбор, и только затем полная сборка.

**Главный принцип:** дизайн выводится из содержания и из найденных референсов, а не из
палитры по умолчанию. Стиль нельзя «взять из головы» — его находят, показывают и согласуют.

## Когда применять

- Нужна презентация с нуля: доклад, защита, питч, лекция, отчёт.
- Колода выглядит «как у всех», или пользователь говорит «нейросетевой дизайн».
- Надо переделать существующую колоду, сохранив содержание.

Не применять для: правки одного слайда по готовому макету, чистки текста, скринкастов.

## Порядок работы

### 0. Бриф (до дизайна)

Собрать одним пакетом вопросов, не по одному:

1. Аудитория и место: зал, проектор, онлайн; свет; дистанция просмотра.
2. Длительность доклада — от неё число слайдов (примерно 1,5–2 минуты на слайд).
3. Материал: что уже есть (текст, данные, картинки), чего не хватает.
4. Ограничения: вузовская методичка, брендбук, обязательные поля титула.
5. Язык и тон.

Если пользователь сказал «делай», предположения выписать одной строкой и идти дальше.

### 1. Исследование (обязательно, без пропусков)

Прочитать `references/research-playbook.md` и выполнить его: несколько поисковых подходов,
5–10 просмотренных источников, выписка системы каждого найденного направления.

Результат — файл `notes/design-research.md` с **2–4 направлениями**, у каждого:

- идея, выведенная из темы (конституция → документ, архив, печать; GPU → чертёж, схема);
- палитра: 3–5 цветов с ролями и долями (фон / текст / акцент);
- типографика: пара шрифтов и их доступность на машине показа;
- сетка и поля;
- один визуальный мотив, который повторяется;
- 2–3 ссылки на референсы и короткое «что именно берём».

Условия: ни одно направление не является стоковым шаблоном; у каждого есть объяснение,
почему оно про эту тему, а не про любую другую.

### 2. Пробники (3 слайда на направление)

Для каждого направления собрать быстрый черновик: **титул, плотный содержательный слайд,
слайд с цифрой или цитатой**. Эти три архетипа вскрывают масштаб, иерархию и ритм.

- 16:9, реальные тексты темы, не lorem.
- Отрендерить в PNG, показать пользователю рядом, с одной строкой различий.
- Спросить: какое направление и что поправить (цвет, кегль, плотность).
- Пробники одноразовые: после выбора код переписывается под финальную систему.

Без согласования направления полную колоду не собирать.

### 3. Сборка

1. В начале генератора — блок «система» комментарием: шрифты, цвета с ролями, сетка,
   правило акцента. Любое дальнейшее решение ссылается на него; новое значение —
   только через правку этого блока.
2. 10–16 слайдов, **разные архетипы**: титул-плакат, тезис, индекс-таблица, цитата,
   число-герой, схема, перелом (полноцветный слайд), выводы, источники.
3. Один фокусный элемент на слайд, 60–80 % визуального веса; остальное тише.
4. Заголовок — утверждение, а не тема: «Изменения принимал народ», а не «Референдумы».
5. Заметки докладчика — одно-два предложения на слайд, не текст со слайда.
6. Технику генерации и подводные камни смотреть в `references/pptx-toolcraft.md`.

### 4. Проверка

Прогнать `references/deck-qa.md` целиком: рендер каждого слайда, список дефектов,
проверка на «нейросетевые» маркеры, валидация файла, доступность шрифтов.

Показывать пользователю рендеры, а не только файл: он должен увидеть то же, что увидит зал.

## Тест на «нейросетевость»

Полный список с контрмерами — `references/anti-ai-checklist.md`. Короткая версия:

| Маркер | Контрмера |
|---|---|
| Скруглённые карточки с иконками | Линейки, отбивки, сетка, воздух |
| Ряд одинаковых плиток с цифрами | Одна цифра-герой плюс тихие спутники |
| Плашка над заголовком, капсовый «eyebrow» | Убрать; номер раздела — мелким в углу |
| Кремовый фон и серифный курсив | Палитра из исследования, один акцент |
| Всё одного веса и размера | Контраст масштаба 5–10 раз |
| Один макет на все слайды | Пять и больше архетипов страниц |
| Тени, градиенты, 3D-буквы | Плоская графика, волосяные линии |

Если удалить элемент и слайд не стал хуже — элемент был украшением.

## Степени свободы

- **Тема и идея.** Обязательно: мотив из предмета (архив, чертёж, каталог, полевая запись).
- **Формат и техника.** pptxgenjs, python-pptx, HTML в PDF — по среде.
- **Стиль.** Только из исследования. Не «просто тёмная тема с синим».

## Частые ошибки

- Пропустить исследование и сразу рисовать: получается средний шаблон.
- Принести один вариант как готовый: пользователь не видел альтернатив.
- Согласовать палитру словами, без пробников: на слайде всё выглядит иначе.
- Собрать 16 слайдов одним макетом: ритм пропадает к пятому.
- Оставить текст, который докладчик и так скажет.
